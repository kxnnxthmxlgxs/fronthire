# FrontHire
 
FrontHire is a responsive job application tracking platform that helps job seekers manage applications, monitor progress, and organise interview opportunities from one dashboard.
 
## Project Status
 
FrontHire is currently under active development.
 
The application currently supports:
 
- Dashboard statistics
- Recent application activity
- Creating job applications
- Viewing job applications
- Editing job applications
- Deleting job applications
- Searching by company, position, or location
- Filtering by application status
- Browser persistence using localStorage
- Responsive desktop and mobile navigation
 
## Technology Stack
 
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React
- Context API
- localStorage
- ESLint or Oxlint
- GitHub Codespaces
 
## Application Statuses
 
FrontHire currently supports the following application stages:
 
- Saved
- Applied
- Assessment
- Interview
- Offer
- Rejected
